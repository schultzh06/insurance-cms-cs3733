---
title: New Business Referral Checklist
subtitle: Complete before sending any file to a senior underwriter
---

# Applicant and property

- [ ] Named insured matches the deed or purchase contract
- [ ] Mailing address and property address both verified
- [ ] Community number and map panel recorded
- [ ] Flood zone confirmed from the current FIRM

# Risk details

- [ ] Foundation type and number of floors confirmed with photos
- [ ] Elevation Certificate attached (if available)
- [ ] Enclosure or basement square footage noted
- [ ] Machinery and equipment location noted (above or below first floor)

# Loss history

- [ ] Five-year loss run attached
- [ ] Severe Repetitive Loss status checked
- [ ] Any open claim explained in notes

# Coverage request

- [ ] Coverage A at or below replacement cost estimate
- [ ] Deductible selection documented
- [ ] Lender requirement letter attached (if applicable)

# Referral reason

Write one or two sentences explaining why this file is being referred and
what decision you need from the senior underwriter.
